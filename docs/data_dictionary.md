# Data Dictionary

This document defines the fields used in the synthetic journal entry dataset.

| Field | Description | Example |
|---|---|---|
| journal_id | Unique journal entry identifier | JE001 |
| posting_date | Date when the journal entry was posted | 2026-06-30 |
| posting_time | Time when the journal entry was posted | 14:30 |
| account_code | General ledger account code | 5100 |
| account_name | General ledger account name | Advertising Expense |
| amount | Journal entry amount in KRW | 2500000 |
| description | Business purpose or journal entry description | Online advertising expense |
| preparer | Employee who prepared the journal entry | EMP001 |
| approver | Employee who approved the journal entry | MGR001 |
| entry_type | Manual or automatic journal entry | Manual |
| evidence_available | Whether supporting evidence exists | Yes |
